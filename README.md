# SmartMark - AI 기반 스마트 북마크 확장 프로그램

Chrome Extension으로 웹페이지를 북마크할 때 AI가 자동으로 요약을 생성하고 썸네일을 만들어주는 스마트 북마크 관리 도구입니다.

## 🌟 주요 기능

- **AI 자동 요약**: Gemini API를 사용하여 웹페이지 내용을 한 줄로 요약
- **썸네일 생성**: 웹페이지의 썸네일 이미지 자동 생성
- **폴더별 관리**: 북마크를 폴더별로 체계적으로 관리
- **중복 방지**: 같은 URL의 북마크 중복 저장 방지
- **스마트 검색**: 저장된 북마크를 AI 기반으로 검색 (개발 예정)


## 🎯 사용법

### 북마크 저장
1. 북마크하고 싶은 웹페이지에서 확장 프로그램 아이콘 클릭
2. 제목과 저장할 폴더 선택
3. "북마크 저장" 버튼 클릭
4. AI가 자동으로 페이지를 분석하고 요약 생성

### 북마크 관리
1. 확장 프로그램 팝업에서 "북마크 관리 페이지 열기" 클릭
2. 폴더별로 저장된 북마크 확인
3. 각 북마크의 AI 요약과 썸네일 확인

## 🛠️ 개발 환경

- **Manifest Version**: 3
- **JavaScript**: ES6+
- **APIs**: Chrome Extensions API, Gemini API
- **Storage**: Chrome Local Storage
